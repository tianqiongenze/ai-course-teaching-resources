# 互动游戏教师手册（77号轮）

> 与《76号报告》配套：40 个课次各 2 个课堂互动游戏，落盘为 40 册独立 PPT + 本手册。

## 一、为什么做交互游戏
- **教育专家视角**：游戏激活'前测-精讲-后测'闭环，课前快问检测预习、课中游戏突破重难点、课后口诀固化记忆。
- **教授级高工视角**：每个游戏都指向可验证的工程判断（漏报代价/阈值权衡/门禁决策），不脱离真实业务。

## 二、游戏类型与适用环节
| 类型 | 玩法 | 建议时长 | 适用环节 |
|---|---|---|---|
| QUIZ | 举手/手势投票 | 2-3分钟 | 课前引入·检测预习 |
| JUDGE | 举牌表决+辩论 | 3-5分钟 | 价值观/工程底线讨论 |
| MATCH | 连线配对 | 2-3分钟 | 概念↔含义固化 |
| RUSH | 抢答风暴 | 3-4分钟 | 知识快测·活跃气氛 |
| SPOT | 找茬 | 3-4分钟 | 错误识别·数据素养 |
| TRY | 动手小实验 | 3-5分钟 | 动手验证·结对编程 |
| RANK | 排序闯关 | 3-4分钟 | 流程/依赖关系理解 |
| GUESS | 估算挑战 | 2-3分钟 | 数量级直觉·业务翻译 |

## 三、计分与课堂组织
1. 分组：建议 4-6 人一组，设组长记分。
2. 计分：答对+2、思路对半+1、答错不扣分（鼓励试错）；小组积分可折入工单评分（加分≤5分）。
3. 节奏：游戏A（课前/课中）→ 精讲 → 游戏B（课中/课后）→ 复盘口诀（2分钟收尾）。
4. 公平：抢答先举手后发言；举牌/手势全班同步，防止跟风。

## 五、与现有资源的关系
- 游戏页**不替换**现有 163 册课件，而是**独立成册**，教师按需投屏引用。
- 游戏中的业务情境（泵站/焊缝/YOLO双路线等）与工单、工程化项目**同一载体**：重庆两江智造集团。
- 答案与讲评页给出'为什么'——可直接用于课末复盘。

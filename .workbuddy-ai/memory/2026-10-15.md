### 六、踩坑（新增）
- **审计器必须先校准再下结论**：v1 的"栅格/安全区/重复页"三项判据全部误报，校准后真实问题=0。
- **autopep8 `--select E1` 会过度校正**续行缩进（E128→E127 来回摆动）→ 只用 `E2,E3,E4,E5,E7,W2,W3`。
- **三引号模板里的 `\` 行尾续行符会被吞**（变成超长单行）→ 模板中必须写 `\\`。
- **flake8 命令行过长**（>511 文件）报 WinError 206 → 必须分批（每批 ≤100 文件）。
- **pycodestyle 进程内 API 比 subprocess 快百倍**；自定义 report 需实现 `init_file/error/get_file_results/increment_logical_line/start/stop`。
- **生成器的修复必须并入构建流程**，否则每次重生成都会还原（本次 E12x 反复出现即此因）。
- **正则写 `F4\d\d` 只匹配 `F401`，漏掉 `F841`**（F841 是 `F8` 开头）→ 用 `F[48]\d\d`。
- **盘符冒号破坏行号正则**：flake8 对**绝对路径**输出 `D:\...` 时 `^(.*?):(\d+)` 会把盘符当分隔符
  → 一律用**相对路径**调用 flake8。
- **鼠标删除式启发式危险**：按"片段内是否出现 rng."判断未用赋值，误删了仍在使用的行 → 产生 F821 回归。
  → 应先小范围试，且删除后立即全量 flake8 复检。
- **starter 的 `lambda`/未用变量属教学脚手架**，用 `# noqa` 标注而非删除。

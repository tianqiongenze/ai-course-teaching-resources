# 软件安装与使用完全指南（文科生照做版）

> **目标读者**：从未装过编程软件的大一新生，照着本指南一步一步做，就能完成所有课程的软件环境准备。
> **适用课程**：Python编程基础 / Python程序设计（项目实战） / AI应用基础（48课时版）
> **装机时间**：约60-90分钟（含下载等待）；装完可一键自检`python check_env.py`
> **联网要求**：安装过程中需要联网下载软件（约1-2GB）；装完后可离线上课

## 第一部分：安装Anaconda（Python运行环境）

> **为什么要装Anaconda**：Anaconda = Python + 常用科学计算库 + 包管理工具conda，一次装好不用逐个pip install。三课都用它。

### 第1步：下载Anaconda安装包

1. 打开浏览器，地址栏输入：**https://www.anaconda.com/download**
2. 页面会自动识别你的操作系统（Windows / macOS），点击大按钮 **"Download"**
3. 等待下载完成（文件约500-800MB，视网速约5-15分钟）

> ⚠️ 如果官网很慢，可用清华镜像：**https://mirrors.tuna.tsinghua.edu.cn/anaconda/archive/**
> 找到最新版（如 `Anaconda3-2025.xx-Windows-x86_64.exe（以官网最新为准）` 或 `Anaconda3-2025.xx-MacOSX-x86_64.pkg（以官网最新为准）`）点击下载

### 第2步：运行安装程序

#### Windows（.exe文件）
1. 双击下载的 `.exe` 文件
2. 点击 **Next** → **I Agree**（选Just Me）
3. 安装路径**建议保持默认**（`C:\Users\你的用户名\anaconda3`）
4. **关键选项**：
   - ☑ **Add Anaconda3 to my PATH environment variable**（勾选！不勾后面要手动配环境变量）
   - ☑ **Register Anaconda3 as my default Python**
5. 点击 **Install**，等待安装完成（约5-10分钟）
6. 安装完成后点 **Next** → **Finish**（不需要安装PyCharm，关掉即可）

#### macOS（.pkg文件）
1. 双击下载的 `.pkg` 文件
2. 一路点 **继续** → **同意** → **安装**（输入电脑密码）
3. 安装路径默认在 `/opt/anaconda3` 或 `~/opt/anaconda3`

### 第3步：验证安装成功

1. **Windows**：按 `Win+R`，输入 `cmd`，回车打开命令提示符
2. **macOS**：打开"终端"（聚焦搜索输入"终端"或"Terminal"）
3. 输入以下命令并回车：
```
conda --version
python --version
```
4. 看到 `conda 25.x.x` 和 `Python 3.12.x` 类似输出 = 安装成功 ✅

> ❓ **如果提示"conda不是内部命令"**（Windows未勾选PATH）：
> 手动添加环境变量：右键"此电脑"→属性→高级系统设置→环境变量→用户变量Path→新建→填入`C:\Users\你的用户名\anaconda3\Scripts`和`C:\Users\你的用户名\anaconda3`→确定→重开cmd

### 第4步：配置国内镜像（加速下载包）

打开终端/命令提示符，逐行输入：
```
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free
conda config --set show_channel_urls yes
```
> 这样以后 `conda install` 和 `pip install` 都走清华镜像，速度10倍提升

### 第4步：为每门课创建 conda 环境（一次性，W1装机课完成）

> **核心操作**：每门课创建一个独立的 conda 环境，课程之间包互不干扰
> 详细说明见 `01-Anaconda安装与使用指南.md` 第三章

打开终端，逐行输入：
```
conda create -n py02 python=3.12 -y      # 02-Python编程基础
conda create -n pp03 python=3.12 -y      # 03-Python程序设计（项目实战）
conda create -n ai48 python=3.12 -y      # 05-AI应用基础（48课时版）
```

验证环境创建成功：
```
conda env list
```
看到 `py02`、`pp03`、`ai48` 三个环境 = 成功 ✅

### 第5步：激活环境并装基础包

```
conda activate py02
pip install numpy pandas matplotlib scikit-learn scipy
```

> ⚠️ **必须先 conda activate 再 pip install**——之后所有课程装包都先激活对应环境

## 第二部分：安装PyCharm CE（代码编辑器）

> **编辑器选择**：本套课程统一使用**PyCharm CE**（社区版免费，工程化功能强）做编码，**Jupyter**做交互实训。
> 详细配置见 `05-PyCharm使用指南.md`；conda 环境选择见 `01-Anaconda安装与使用指南.md` 第六章。

### 第1步：下载安装

1. 浏览器输入：**https://www.jetbrains.com/pycharm/download/**
2. 下载左侧的 **Community Edition**（免费版 — 不要下右侧的 Professional 试用版）
3. **Windows**：双击 `.exe` → 一路Next → ☑ "Add launchers dir to the PATH" + ☑ ".py 关联" → Install
4. **macOS**：下载后把PyCharm CE拖入"应用程序"文件夹

### 第2步：首次启动与新建项目

1. 打开 PyCharm CE → 勾选确认 → Continue → 主题自选（Light/Darcula）
2. 点 **New Project** → Location 选课程包目录（如 `hello_python`）
3. **Python Interpreter** 选 **Previously configured interpreter** → **Add Interpreter** → **Conda Environment** → 选 Anaconda 环境列表中的 conda 环境

> ⚠️ **不要选 "New environment using Virtualenv"**——本课程统一用 conda 环境（见第一部分第4步）

### 第3步：确认Python解释器

1. 菜单 **File → Settings**（macOS: **PyCharm → Settings**）
2. 左侧 **Project → Python Interpreter**
3. 确认显示的是 **conda 环境** 的 Python（路径含 `anaconda3\envs\环境名\python.exe`）

### 第4步：验证——运行第一个程序

1. 在项目树中右键 → 新建文件，命名为 `hello.py`
2. 输入：
```python
print("Hello, Python！我在两江智造等你")
```
3. 右键 → **Run 'hello'**（或点右上角 ▶ 播放按钮运行）
4. 底部 Run 窗口显示 `Hello, Python！我在两江智造等你` = 成功 ✅

## 第三部分：安装Jupyter Notebook（交互式编程）

> **为什么要装Jupyter**：Python编程基础W8起、AI48全程用Jupyter做实训——一行一行跑代码、即时看结果、图表内联显示

### 第1步：安装Jupyter

**方式A（推荐，通过Anaconda）**：
```
conda install jupyter
```

**方式B（如果没装Anaconda，用pip）**：
```
pip install notebook
```

### 第2步：启动Jupyter Notebook

1. 在终端/命令提示符中，`cd` 到你要存放代码的文件夹：
```
cd Desktop/hello_python
```
2. 输入：
```
jupyter notebook
```
3. 浏览器自动打开，显示文件列表页面 = 成功 ✅

### 第3步：新建并运行Notebook

1. 在Jupyter页面右上角点 **New** → **Python 3 (ipykernel)**
2. 新页面打开，看到一个空白的输入框（叫"Cell"单元格）
3. 在Cell中输入：
```python
import sys
print(f"Python版本: {sys.version}")
print("Jupyter启动成功！")
```
4. 按 **Shift+Enter** 运行这个Cell
5. 看到输出 = 成功 ✅

### 第4步：常用快捷键（背下来效率翻倍）

| 快捷键 | 作用 |
|--------|------|
| `Shift+Enter` | 运行当前Cell并跳到下一个 |
| `Ctrl+Enter` | 运行当前Cell不跳走 |
| 在命令模式按`A` | 在上方插入新Cell |
| 在命令模式按`B` | 在下方插入新Cell |
| 在命令模式按`DD` | 删除当前Cell |
| 在命令模式按`M` | 把Cell改成Markdown文本 |
| 在命令模式按`Y` | 把Cell改回代码 |

> "命令模式"=Cell左侧蓝色竖条时（按Esc进入）；"编辑模式"=光标在Cell内时（按Enter进入）

### 第5步：在PyCharm中也能用Jupyter

> PyCharm CE装了Jupyter插件后，直接打开 `.ipynb` 文件就能用，不用启动浏览器版

1. 在PyCharm中打开一个 `.ipynb` 文件（如工单配套的Jupyter实训文件）
2. 顶部选择内核（选课程 conda 环境）
3. 和浏览器版完全一样的操作（Ctrl+Enter 运行当前Cell / Shift+Enter 运行并跳到下一个）

## 第四部分：安装Git与注册GitHub（所有课程第1周装机即完成）

> Git 是**所有课程的必用工具**（不只是03课）——02/03/05每周工单代码都要提交到 GitHub/Gitee。详细操作见 `03-Git与GitHub-Gitee使用指南.md`（含 PyCharm 集成步骤）。

### 第1步：下载安装

1. 浏览器输入：**https://git-scm.com/downloads**
2. 选你的系统 → 下载安装包
3. **Windows**：双击exe → 一路Next（保持默认选项即可）
4. **macOS**：下载pkg → 安装（或 `brew install git`）

### 第2步：验证

终端输入：
```
git --version
```
看到 `git version 2.x.x` = 成功 ✅

### 第3步：注册GitHub账号（首选GitHub；不能正常使用时切换Gitee）

1. 打开 **https://github.com** → 点 **Sign up** 注册（用学校邮箱可申请 Student Pack 免费优惠）
2. 如果 GitHub 注册或访问困难，改用 **https://gitee.com**（国内访问快，注册流程相同）
3. 在终端配置（一次性，全局生效）：
```
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
git config --global init.default branch main
```
4. 保存密码（避免每次输入）：
```
git config --global credential.helper manager   # Windows
git config --global credential.helper osxkeychain  # macOS
```

### 第4步：创建仓库并克隆

1. GitHub/Gitee 网页上点 **+ → New repository** → 仓库名如 `py-homework` → ✅勾选 README → 创建
2. 复制仓库 HTTPS 地址 → 终端克隆到课程包目录：
```
git clone https://github.com/你的用户名/py-homework.git
```
3. 如果 clone 超时 → 先注册 Gitee，按 `03-Git与GitHub-Gitee使用指南.md` 第十节"切换到Gitee"操作（两步完成）

> 📖 详细操作（五步工作流/commit前缀规范/PyCharm中Git/冲突解决/Gitee切换）见 **`03-Git与GitHub-Gitee使用指南.md`**

## 第五部分：为每门课创建 conda 环境并安装 Python 包

> **核心原则**：每门课用 conda 创建独立环境——一门课一套依赖互不打架
> 详细命令见 `01-Anaconda安装与使用指南.md` 第三章

### 第1步：创建课程环境（W1装机课完成，一次性）

打开终端，逐行输入（每门课一个环境）：
```
conda create -n py02 python=3.12 -y      # 02-Python编程基础
```

### 离线机房安装法（机房无外网时）

1. 在有网的电脑上下载所有包到u盘：

```
pip install --no-index --find-links=D:\wheels\ numpy pandas matplotlib
```

## 常见问题（FAQ）

| 问题 | 解决方案 |
|------|---------|
| `conda不是内部命令` | 环境变量没配→见Anaconda第3步说明 |
| `pip install很慢` | 配清华镜像（第4步）或加`-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `Jupyter打不开浏览器` | 终端会显示一个带token的URL，复制到浏览器手动打开 |
| `PyCharm运行.py提示"没有Python解释器"` | File→Settings→Python Interpreter→Conda Environment→选课程conda环境 |
| `wordcloud中文显示方框□` | 指定中文字体路径：`font_path = "fonts/SourceHanSansCN-Regular.otf"` |
| macOS权限被拒 | 系统设置→隐私与安全性→允许运行被阻止的软件 |
| 安装torch很慢 | 必须加`--index-url https://download.pytorch.org/whl/cpu`只装CPU版（约200MB） |

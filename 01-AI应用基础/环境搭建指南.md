# 《AI应用基础》机房环境搭建指南（开课前一周执行）

> 目标：全部8个工单在**无外网、无GPU**的机房100%可实施。

## 一、硬件与系统要求

| 项目 | 最低要求 | 说明 |
|------|---------|------|
| CPU | i5及以上 | M2.1/M2.2深度学习为tiny模型CPU训练，单轮约1-3分钟 |
| 内存 | 8GB | |
| 磁盘 | 每机5GB可用 | torch CPU版约1.5GB |
| 网络 | 不依赖外网 | 全部依赖与数据从资料包/内网文件服务器导入 |

## 二、部署步骤（教师机→学生机镜像）

1. **基础环境**：安装 Anaconda（含 Python 3.12+）、PyCharm CE（选conda环境作为解释器）。
2. **依赖安装（离线）**：
   ```bash
   # 教师机在外网一次性下载全部wheel：
   pip download -r requirements.txt -d offline_wheels/
   pip download torch --index-url https://download.pytorch.org/whl/cpu -d offline_wheels/
   # 学生机离线安装：
   pip install --no-index --find-links=offline_wheels/ -r requirements.txt
   ```
3. **生成全部本地数据**（生成后连同代码框架拷贝到学生机 `data/` 目录）：
   ```bash
   python 数据与工具/generate_data.py all      # 生成 M1/M2/M3/M4 全部数据（约1分钟）
   ```
4. **启动本地模拟LLM并自测**（第13周课内环境，教师机做服务器即可）：
   ```bash
   python 数据与工具/mock_llm_server.py          # 默认监听 127.0.0.1:8000
   curl -X POST http://127.0.0.1:8000/v1/chat/completions -H "Content-Type: application/json" \
        -d '{"messages":[{"role":"user","content":"泵振动超标怎么处理？"}]}'
   ```
5. **YOLO权重（第11周）已随包就绪**：`data/weights/yolov8n.pt`（6.5MB）与 `yolov8n.onnx`（12.8MB，已验证可用）随资料包分发，教师无需再下载。注意：ONNX输出格式为(84,8400)（0-3=xywh，4-83=类别分数），starter已按此解析。课堂素材：实物照片用手机拍键盘/水杯即可；包内 `zidane.jpg/bus.jpg`（ultralytics安装目录assets下）可作备选演示图。

## 三、逐项环境验证清单（开课前逐机勾检）

- [ ] `python 学生代码框架/m11_starter.py --check` 输出"环境OK"

- [ ] 教师机 `mock_llm_server.py` 启动后，学生机 `curl http://<教师机IP>:8000/health` 返回 ok
- [ ] 屏保/还原卡设置确认：重启后数据目录不丢失（或每次课前重发数据）

## 四、常见故障预案

| 现象 | 原因 | 处置 |
|------|------|------|
| torch安装失败 | 磁盘/权限 | 改用共享目录venv模板整体拷贝 |
| 中文字体乱码（图表） | matplotlib缺中文字体 | 统一代码 `plt.rcParams['font.sans-serif']=['SimHei','Arial Unicode MS']`；资料包附 `SimHei.ttf` |
| mock LLM连不上 | 防火墙/端口 | 改端口8800；或每机自起服务（127.0.0.1） |
| YOLO推理慢 | CPU性能低 | imgsz降到320、conf阈值0.4起调 |

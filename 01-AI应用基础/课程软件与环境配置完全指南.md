## 二、基础环境三步装（学生机）

1. **Anaconda+conda环境**：安装Anaconda→创建课程环境`conda create -n ai01 python=3.12 -y`→激活`conda activate ai01`（详见`../软件操作指南/01-Anaconda安装与使用指南.md`）
2. **装PyCharm CE**：装Python扩展；选conda环境`ai01`作为解释器（详见`05-PyCharm使用指南.md`第三章）
3. **装依赖**（有网；**必须先`conda activate ai01`再装**）：
   ```bash
   conda activate ai01
   cd 本包目录
   pip install -r requirements.txt
   pip install torch --index-url https://download.pytorch.org/whl/cpu
   ```
   **离线机房**：教师机先 `pip download -r requirements.txt -d offline_wheels/` 与 `pip download torch --index-url .../cpu -d offline_wheels/`，学生机：
   ```bash
   conda activate ai01
   pip install --no-index --find-links=offline_wheels/ -r requirements.txt
   ```

## 五、环境故障排查（本课实测案例）

| 现象 | 原因 | 解决 |
|------|------|------|
| `pip install torch`装成GPU版巨大/失败 | 默认源含CUDA | 必须加`--index-url .../whl/cpu` |
| 装torch后matplotlib/wordcloud报错 | 旧版torch与numpy 2.x不兼容 | `pip install --upgrade torch`（torch 2.14+已兼容numpy 2.x，升级torch而非回退numpy） |
| ONNX输出shape与教程不符 | YOLOv8导出为(84,8400) | 按starter解析：`cls=out[4:]`取max |
| `Connection refused`（M4.2） | mock服务未启动/端口不符 | 先启`mock_llm_server.py`；starter改`BASE_URL`为教师机IP |
| Jupyter找不到内核 | 多Python环境 | `python -m ipykernel install --user` |

## 三、使用流程（六步法落地）

1. **课前（资讯·计划）**：在课程平台发布当周工单任务书+starter；学生完成导学单预习自测，提交初步计划。
2. **课中**：决策10min（工单内含决策矩阵页）→第一轮实施30min→三层检查复盘5min→第二轮实施25min→总结评价10min（共80分钟，每课时40分钟）。
3. **课后24h内**：按工单内D/C/B/A量表评分并反馈；困难学生推送补强任务。
4. **每4周**：ABCD角色轮换（用04-教学管理工具包的轮换表）。

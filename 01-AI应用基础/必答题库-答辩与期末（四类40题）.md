# 《AI应用基础》必答题库（答辩与期末·四类×10题·含答案要点）

> 用法：综合项目答辩必答3题（架构/数据流/异常处理各1）+抽答1题；期末上机理论口试从本库抽6题。评分：要点覆盖≥70%记通过。

## 一、系统架构类（A1-A10）

| # | 题目 | 答案要点 |
|---|------|---------|
| A1 | 画出你的故障诊断系统架构并说明各模块职责 | 数据层(CSV/NumPy)→特征层→模型层(sklearn封装为类)→评估层→预测服务；模型即对象的OOP封装 |
| A2 | 为什么用面向对象封装AI系统？相比脚本式优点？ | 复用(继承AIModel基类)、可替换(统一predict/evaluate接口)、可测试、便于集成多模型 |
| A3 | CNN与全连接网络在图像任务上的本质区别？ | 局部感受野+权值共享→参数量骤减、保留空间结构；池化带来平移鲁棒性 |
| A4 | LSTM为何适合轴承寿命预测？普通网络差在哪？ | 时序记忆门控(遗忘/输入/输出)，能建模长程退化趋势；普通网络把窗口当独立特征丢失时序语义 |
| A5 | YOLO"一次看全图"是什么意思？与滑窗法区别？ | 单次前向输出全图候选(网格+anchor)，端到端快；滑窗重复计算慢、需后处理 |
| A6 | RAG系统的两个核心组件？为什么不让LLM直接答？ | 检索器(本地知识库)+生成器(LLM)；直接答有幻觉且知识过期，RAG以检索结果为据、可溯源 |
| A7 | Agent与普通LLM调用的区别？ | Agent=LLM+工具调用+多步规划循环(感知→决策→工具→观察)，可完成复合任务 |
| A8 | 训练/评估/推理三阶段为何要分离部署？ | 资源异构(GPU训练/CPU推理)、版本管理、服务稳定性、安全隔离(训练数据不出域) |
| A9 | 你的智能助手中KnowledgeBase类如何设计接口？ | load/retrieve(query,topk)两个方法；返回（条目，相似度）；便于替换关键词或TF-IDF实现 |
| A10 | 轻量化模型(ONNX/TFLite)解决什么工程问题？ | 去除训练依赖、减小体积、跨端推理加速；边缘设备算力/内存受限 |

## 二、数据流类（B1-B10）

| # | 题目 | 答案要点 |
|---|------|---------|
| B1 | 叙述M1.1从CSV到预测输出的完整数据流 | 读CSV→X/y分离→分层划分→训练→预测→四指标评估→结果落盘/展示 |
| B2 | 训练集与测试集为什么要分层划分？ | 保持类别比例一致；否则小类在测试集缺失或占比失真，指标不可信 |
| B3 | 特征工程中"消融实验"如何组织数据流？ | 固定测试集不变，逐步叠加处理(清洗→新特征→缩放→调参)，每步记录指标，定位增益来源 |
| B4 | 滑动窗口如何从一条序列造出监督样本？ | X=前w步, y=第w+1步的RUL；步长1滑动；注意X与标签对齐防泄漏 |
| B5 | 图像预处理的归一化为什么在划分后只fit训练集？ | 防数据泄漏；用全量统计量会把测试分布信息泄入训练 |
| B6 | TF-IDF的"数据流"：一条故障文本到类别标签？ | 分词→停用词过滤→向量化(训练fit的词表)→分类器预测→概率输出 |
| B7 | RAG链路中用户问题经历了什么变换？ | 检索向量化/关键词→TopK知识→Prompt组装(CONTEXT前缀)→LLM→答案+依据标注 |
| B8 | YOLO输出(84,8400)张量如何变成检测框？ | 0-3行xywh、4-83类分；取每列最大类分当conf，过滤阈值→NMS→坐标还原到原图 |
| B9 | 模型服务化后一次请求的数据流与耗时瓶颈？ | JSON解析→特征组装(需与训练列序一致)→推理(ms级)→序列化返回；瓶颈多在特征组装与IO |
| B10 | 决策矩阵在你项目里影响了哪一步数据流？ | 如选随机森林→影响特征重要性输出分支与后续报告图表生成 |

## 三、异常处理与工程健壮性类（C1-C10）

| # | 题目 | 答案要点 |
|---|------|---------|
| C1 | 模型上线后预测全部返回同一类，怎么排查？ | 查输入分布漂移(统计训练/线上特征)→检查特征顺序/归一化是否一致→类别不均衡→再训练校准 |
| C2 | 调LLM服务超时/500，你的容错设计？ | timeout+有限重试(退避)→降级话术→错误日志留痕；演示HALLUCINATE=1场景 |
| C3 | 什么情况下准确率高但模型不可用？ | 类别极度不均衡(99%正常)：全预测正常acc=99%但召回=0；要看召回/F1与业务代价 |
| C4 | 数据中30%温度缺失，删除还是填充？决策依据？ | 看缺失机制与下游任务：随机缺失且量小可插值；系统性缺失需探究原因；记录决策矩阵 |
| C5 | 训练loss下降但验证指标变差说明什么？怎么办？ | 过拟合；早停/正则/数据增强/减模型容量/交叉验证确认 |
| C6 | OpenCV测量结果偶发跳变，可能原因？ | 阈值临界震荡→滞后阈值/形态学稳定；光照变化→自适应阈值或固定光源；轮廓粘连→分水岭 |
| C7 | ONNX推理与训练框架结果不一致，排查顺序？ | opset版本→预处理是否一致(尺寸/BGR-RGB/归一化)→输入dtype→逐层输出对比 |
| C8 | Prompt改造后回答变差，如何科学归因？ | 固定问题集A/B对比、单变量修改、记录评分；避免"感觉式"调优 |
| C9 | 你的系统哪里最容易在产线"翻车"？ | 数据漂移、长尾工况未覆盖、阈值过拟合测试集；需监控与再训练机制 |
| C10 | 单元测试在AI项目里测什么？ | 数据管道(形状/空值)、特征函数(数值断言)、模型接口(输入输出形状)、服务(状态码) |

## 四、合规与职业素养类（D1-D10）

| # | 题目 | 答案要点 |
|---|------|---------|
| D1 | 为什么课堂用本地模拟LLM而非直接公网API？ | 数据不出域(工业数据保密)、网络/费用不可控、结果可复现；真实API需脱敏与授权 |
| D2 | 使用企业脱敏数据要遵守什么？ | 最小必要、不外传、不逆向还原、用后按约销毁；签署使用承诺 |
| D3 | AI模型决定"停机"决策的伦理边界？ | AI辅助建议、人做最终决策并留痕；高代价动作必须有人工复核位 |
| D4 | 什么是算法偏见？在你的分类任务里如何体现？ | 训练分布偏(某类样本少)→该类召回低；用分层采样、类别权重、分群指标审视 |
| D5 | 模型可解释性为什么在工业场景重要？ | 追责、审计、工程师信任；SHAP/特征重要性/注意力的最低要求 |
| D6 | 预训练权重的开源许可证要注意什么？ | 商用限制(GPL传染)、署名要求；记录来源与版本 |
| D7 | 知识库内容侵权的风险点？ | 直接搬运手册条文→用内部规范或授权文档；引用注明出处 |
| D8 | 你的日报系统给谁看？误报的责任链？ | 面向班组与管理；误报需标注置信度与"建议复核"，避免误导排产 |
| D9 | 绿色计算在你的项目如何体现？ | 向量化省算力、CPU轻量推理、避免无效全量重训(增量/缓存) |
| D10 | 毕业后如何持续跟上AI迭代？ | 官方文档/论文跟踪、复现工单化、个人代码库沉淀、企业实习实践 |

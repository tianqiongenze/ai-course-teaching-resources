# 设备运维脱敏数据集 v1.0（教学版）

> **性质声明**：本数据集为**按真实工业规律合成的教学模拟数据**，字段结构、脱敏流程、文档规范均按企业数据交付标准设计；待校企签订数据授权后可直接用真实数据替换同名文件。

## 文件清单
| 文件 | 内容 | 规模 |
|------|------|------|
| device_metrics.csv | 设备运行参数（温度/压力/振动/电流+四类标签） | 600条 |
| fault_texts.csv | 脱敏故障报文文本（四类） | 240条 |
| 数据字典.md | 逐字段定义、单位、取值范围 | — |
| 脱敏SOP.md | 脱敏标准操作流程（可复用于真实数据） | — |
| 数据使用授权承诺书.md | 学生/教师签署模板 | — |

## 快速使用
工单M1.1/M1.2/M4.1可直接读取本数据集替代 `data/pump_fault.csv` / `data/fault_reports.csv`（列名一致或按数据字典映射）。

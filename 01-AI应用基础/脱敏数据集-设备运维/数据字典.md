# 数据字典

## device_metrics.csv
| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| device_id_pseudo | str | - | 伪匿名设备号(EQxxx, 已脱敏) |
| station | str | - | 工位/泵站代号(脱敏映射表由数据管理员保管) |
| temp_c | float | ℃ | 40-80, 轴承磨损类整体上移 |
| press_mpa | float | MPa | 0.2-0.55, 叶轮堵塞类下移 |
| vib_mm_s | float | mm/s | 1-7, 故障类显著抬升 |
| current_a | float | A | 9-13 |
| label | str | - | 无故障/轴承磨损/叶轮堵塞/联轴器失衡 |

## fault_texts.csv
| 字段 | 类型 | 说明 |
|------|------|------|
| text | str | 脱敏故障报文(设备以工位代号指代) |
| label | str | 同上四类 |

# 02 架构说明（TOGAF 四域视角）

> 项目：故障报告文本分类

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 报修单自动分派到对应班组，缩短响应时间 |
| 数据架构 | (故障描述文本, 类别) 语料 → 二元词 → TF-IDF → 分类模型；输出指标与在线预测 |
| 应用架构 | core 分词/特征化/双模型评估/在线预测；pipeline 编排 |
| 技术架构 | Python 3.12 + conda ai01；numpy/sklearn；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 分词/TF-IDF/双模型/在线预测 | `tokens()/build()/evaluate()/predict()` |
| `pipeline.py` | 语料→训练→对比→演示 | `run(cfg, out_dir)` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置

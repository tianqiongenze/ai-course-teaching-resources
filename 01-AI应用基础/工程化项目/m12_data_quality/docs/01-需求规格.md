# 01 需求规格说明（GB/T 9385《计算机软件需求规格说明规范》）

> 项目：特征工程优化的故障诊断系统（01-AI应用基础 · W05 第2次课 · 工单 M1.2）
> 文档版本：v1.1　编制日期：2026-10-28　密级：教学内部

## 1. 范围
在工单 M1.1 的三个分类器之上，**不换主算法**（仍为逻辑回归），只做数据与特征侧优化：
物理量程校验 → 缺失填补 → 跨通道派生特征 → 标准化 → 训练折内网格搜索，并用**消融实验**
逐步量化每一步的贡献（百分点），最终给出"数据处理决定模型上限"的因果解释。
同时保留原有脏数据画像与"完整率×合理率"质量分口径，作为噪声样本处理策略的证据。

## 2. 术语与缩略语
| 术语 | 释义 |
|---|---|
| 工单 | 企业派发的任务单，本项目的需求来源（M1.2） |
| TOGAF 四域 | 业务/数据/应用/技术四个架构视角 |
| ABCD | D学徒/C操作员/B组长/A师傅 分层达标线 |

| 数据泄漏 | 用测试集统计量做填补/缩放/调参；本项目所有 fit 只在训练折内进行 |

## 3. 用户故事与验收标准
| 编号 | 用户故事 | 验收标准（工单 M1.2 第四节） |
|---|---|---|
| US-01 | 作为学员，我希望看到清洗带来的真实提升 | 及格(D) 较基线提升 ≥5 个百分点，且代码规范率 ≥70%（工单第四节原文还写了这条，`stylecheck` 实测） |
| US-02 | 作为学员，我希望消融记录成表 | 良好(C) 提升 ≥7 且消融表覆盖清洗/派生/缩放/调参 |

| US-06 | 作为讲师，我要结果可复现 | 缺陷注入与划分均带固定种子；二次运行 diff 为空 |

## 4. 功能需求
| 编号 | 功能点 | 说明 |
|---|---|---|
| F-01 | 真实数据加载 | `core.load_pump_csv()` 读 `data/pump_fault.csv`（450×5，三类各 150）；缺文件直接 `FileNotFoundError`，不用合成数据冒充验收结果 |
| F-02 | 现场采集视图 | `core.field_view()` 按配置比例把单元写成 0（掉线）并注入温度满量程尖峰，种子固定 |
| F-03 | 物理量程校验 | `PHYS_RANGES` 判定"采集缺陷 vs 真实工况"，越界计数进报告 |
| F-04 | 派生特征 | ≥2 条跨通道特征：振动/电流比、温度×压力积（`core.derive_features()`） |
| F-05 | 缩放对照 | none / Standard / MinMax × 线性主算法与随机森林对照，实测"树模型对单调缩放不敏感"（工单常见错误②） |
| F-06 | 训练折内调参 | `core.grid_search()` 用 StratifiedKFold 只在训练集内切折（工单常见错误③） |
| F-07 | 消融实验表 | 基线 → +清洗 → +派生 → +缩放 → +调参 五档，含 acc、macro-F1、相对基线 pp、关键类召回、lbfgs 迭代数 |
| F-08 | 稳定性 | 训练集 5 折 accuracy 均值 ± 标准差 + 各折明细 |
| F-09 | 质量分口径 | 合成现场日志三类脏数据 → 清洗前后"完整率×合理率"留痕（既有能力保留） |

## 5. 非功能需求
| ID | 类别 | 要求 | 验证方式 |
|---|---|---|---|
| NF-1 | 可复现 | 固定随机种子（划分、缺陷注入、CV 折），重复运行结果一致 | 二次运行 diff |
| NF-2 | 可移植 | numpy + pandas + scikit-learn；缺 sklearn 时报明确错误而非静默降级 | `pip install -r requirements.txt` 后运行 |
| NF-3 | 可配置 | 缺陷率、C 网格、折数、四档门槛全部在 `config/rules.yaml` | 改配置不改代码（`miss_rate: 0` 即回实验室口径） |
| NF-4 | 可测试 | pytest 用例 ≥ 20，覆盖正常/边界/异常 + 工单档位断言 | `python -m pytest -q` |
| NF-5 | 诚实口径 | 报告同时给出口径A（现场）与口径B（实验室）的真实数字，不隐藏"数据太干净→无提升空间" | docs/04 与 output/report.txt 对照 |

## 6. 接口约束
- CLI：`python run.py [--config CONFIG] [--outdir DIR] [--quiet]`
- 配置：`config/rules.yaml`（格式见 docs/05）
- 输出：`output/report.txt`、`output/result.json`

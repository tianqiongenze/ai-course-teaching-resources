# 02 架构说明（TOGAF 四域视角）

> 项目：RAG 运维知识库问答

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 让运维知识'可引用、可追溯'，把'老师傅经验'变成组织资产 |
| 数据架构 | 知识条（category/text）→ 切分为二元词集合 → 学习 overlap_index 重排序 → Top-k+ID=引用 |
| 应用架构 | core 知识加载/重合检索/引用生成/日志；pipeline 批量问答并输出命中率 |
| 技术架构 | Python 3.12 + conda ai01；零第三方依赖；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 知识加载/重合检索/引用生成 | `load_kb()/retrieve()/answer()` |
| `pipeline.py` | 批量问答→命中率统计 | `run(cfg, out_dir)` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置

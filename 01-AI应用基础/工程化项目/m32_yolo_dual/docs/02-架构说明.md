# 02 架构说明（TOGAF 四域视角）

> 项目：YOLO实时缺陷检测（双路线对照）

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 为'要不要微调模型'提供证据；同时守住'没有数据前也有版可用检测器'的底线 |
| 数据架构 | 合成工业图+真值框（YOLO格式标注）→ 两路线检出结果 + IoU 匹配统计 |
| 应用架构 | core 造图/传统检测/IoU/预训练推理；pipeline 双路线并行对照 |
| 技术架构 | Python 3.12 + conda ai01；numpy/Pillow；pytest（预训练权重可选） |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 造图/传统检测/IoU/预训练推理 | `make_scene()/cv_detect()/iou()/yolo_pretrained()` |
| `pipeline.py` | 双路线并行对照 | `run(cfg, out_dir)` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置

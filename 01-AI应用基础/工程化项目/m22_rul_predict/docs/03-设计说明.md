## 2. 核心算法/规则
1. **数据与切分**：真实 npz（30 台 × 180 窗 × 20 列，RUL 归一化 1→0）；设备号由"每台首窗
   RUL=1"从数据本身推出（不硬编码）；按**设备**留出台数 `n_test_devices`，同一台设备的
   全部窗口只出现在一侧 → 指标才算真泛化。
2. **主模型（工单指定）**：1 层 LSTM（hidden=32，batch_first）取末窗输出接 Linear(32→1)，
   Adam(lr=0.003)、MSE 损失、epochs≤60；`torch` 缺失时 `train_lstm` 返回 None，
   流程自动改交实测最优 sklearn 模型并印 MISS。
3. **对照与增益（C 档）**：同一切分上 Ridge 作线性基线，增益 = 基线实测 MSE − LSTM 实测 MSE，
   只有正数才判"说明了增益"；另附"训练均值常数预测"最傻基线，说明特征本身的信息量。
4. **多模型对比（B 档）**：Ridge / 随机森林 / LSTM 逐个真训真测，报告出逐模型
   R²/RMSE/MSE/MAE 表 + 自动生成的机制解读行（差异全部体现在实测数字里）。
5. **拐点分析（A 档）**：中心式双重滑动均值（span）平滑 → 一阶差分达"实测最大升程 ratio 倍"
   并持续 hold 个循环判为斜率拐点；另用"健康基线 + 总抬升 10%"水平法交叉验证。机群 30 台
   逐台实测取中位作参照，检测值与参照的偏移是**实测结论**；拐点竖线画进落盘曲线图。
6. **窗口敏感性（A 档）**：固定 Ridge 与切分，只把历史窗口列数按 `windows` 清单截短，
   逐档真训真测 MSE，输出表 + 折线图 + CSV；非法/超宽的档直接丢弃，不凑数。
7. **判档（tiers.verdict）**：档位递进制——高档累计低档功能门（工单 A 档原文"达B且"），
   数值门比较符号照抄工单（D/B 严格小于、C 小于等于）；测不到的一律 None/False → 判缺 +
   MISS。`claimed` 取"通过的最低序号档"，代码里不留任何自宣言常量。

## 3. 异常处理策略
原则：**跑不出来就判缺，不冒充达标**——所有降级路径都在报告里印 MISS 并写进
`result.json` 的 `tiers.measured.miss_note`。

| 异常/缺失 | 触发场景 | 处理 | 对应测试 |
|---|---|---|---|
| FileNotFoundError | 配置文件缺失 | `config.load_config` 抛出并提示路径，不静默兜底 | test_config.py::test_missing_config_raises |
| 数据文件缺失/不可读 | `data/bearing_rul.npz` 不在盘或键名/形状不符 | `core.load_bearing_windows()` 返回 None → `core.synth_devices()` 同口径兜底，`source/synthetic` 字段如实标注 | test_tiers.py::test_real_bearing_npz_is_used |
| torch 缺失 | `import torch` ImportError | `train_lstm()` 返回 None → 改交实测最优 sklearn 模型，C 档"说明 LSTM 增益"判缺 + MISS（不伪造增益） | test_tiers.py::test_C_lstm_gain_over_linear_baseline_is_measured |
| matplotlib 缺失 | `_plot_backend()` 捕获 ImportError 返回 None | 不生成 png → `viz_ok=False`，D 档"完成预测与可视化"判缺 + MISS | test_tiers.py::test_claim_drops_when_gain_or_models_or_plots_missing |
| yaml/pycodestyle 缺失 | 无 PyYAML / 无 linter | 走内置 `yaml_lite` / 内置兜底检查器，引擎名如实写明"内置兜底" | test_config.py::test_yaml_lite_basic |
| 拐点未检出 | 平滑序列无满足持续条件的上升 | `knee_cycle=None` → 报告该行印 MISS，A 档该条件判缺 | test_tiers.py::test_A_knee_analysis_is_measured_on_the_curve |
| 窗口清单非法 | `windows` 为空 / 含非正整数 / 超出特征列数 | 逐项丢弃不报错，真跑出 MSE 的档数不足 `min_windows` → A 档判缺 | test_tiers.py::test_A_window_sensitivity_has_real_per_window_mse |

## 4. 命名与代码规范
- PEP 8；`snake_case`（函数/变量）、`PascalCase`（类）、`UPPER_CASE`（常量）
- docstring 三件套：做什么 / 参数 / 返回
- 单元函数 ≤40 行，超过则拆分

# 05 运行手册

## 1. 环境准备
```bash
conda create -n ai01 python=3.12 -y
conda activate ai01
pip install -r requirements.txt      # requirements.txt 即精确版本锁定清单（== 锁定）
```

## 2. 运行
```bash
python run.py                     # 默认配置，全流程实跑并落盘 output/
python run.py --quiet             # 只落盘不打印正文
python run.py --config config/rules.yaml
python run.py --outdir output/
python run.py --tier              # 实跑并打印工单四档"实测"判定（承诺档位来自实测）
python run.py --style-only        # 只做 PEP 8 体检（有违规时退出码 1）
python run.py --check             # 环境自检：torch / matplotlib 等可用性
python run.py --set mse_b=0.05    # 临时覆盖配置（可重复；验证"改配置不改代码"）
```

## 3. 配置说明（config/rules.yaml）
| 键 | 含义 | 默认 |
|---|---|---|
| warn / danger / unit | 振动阈值与单位口径 | 80.0 / 95.0 / c |
| seed | 随机种子（切分与训练都可复现） | 7 |
| topk | 检索/排序取前 k | 3 |
| tiers.mse_d / mse_c / mse_b | **工单原文数字**：D<0.15、C≤0.12、B<0.10（A 达 B） | 0.15 / 0.12 / 0.10 |
| n_test_devices | 设备级留出的留出台数（同设备不跨侧，防泄漏） | 8 |
| fallback_devices / fallback_windows | npz 不在盘时的兜底合成规模 | 30 / 180 |
| lstm_epochs / lstm_hidden / lstm_lr / lstm_batch | 工单指定 LSTM 结构（epochs≤60、hidden=32） | 60 / 32 / 0.003 / 128 |
| ridge_alpha / rf_estimators / rf_min_samples_leaf | B 档对照的 sklearn 模型参数 | 1.0 / 80 / 3 |
| windows | A 档窗口长度敏感性清单 | [5, 10, 20] |
| min_windows | 真跑出 MSE 的档数下限（**兜底口径，非工单数字**） | 2 |
| knee_span / knee_ratio / knee_hold | 拐点检测算法参数（**兜底口径，改了就改变实测拐点**） | 15 / 0.5 / 5 |
| min_png_bytes | png 判"已绘制"的字节下限（**兜底口径，工单未给字节下限**） | 1000 |
| style_min | 规范率证据段的显示线（工单未逐档规定规范率，不参与判档） | 90.0 |
| n_cycles / n_train / test_size | 旧轻量轨迹路径参数（零依赖兜底演示保留） | 3000 / 24 / 0.25 |

## 4. 输出物
| 文件 | 内容 |
|---|---|
| output/report.txt | 完整过程报告（含『验收档位判定（实测）』段，过程性证据） |
| output/result.json | 结构化结果 + `tiers.measured`/`gates`（供下游与答辩取数） |
| output/prediction_curve.png | 真值 vs 预测 RUL 曲线 + 实测拐点竖线（D 档机检证据） |
| output/window_sensitivity.png / .csv | 窗口长度 vs 留出 MSE（A 档敏感性证据） |
| output/test_run/ | `pytest` 端到端用例的临时产物目录（与正式产物隔离） |

## 5. 常见问题
| 现象 | 原因 | 处置 |
|---|---|---|
| `ModuleNotFoundError` | 未安装依赖 | `pip install -r requirements.txt` |
| 配置不生效 | 未传 --config | 使用默认 `config/rules.yaml` |
| 中文乱码 | 控制台编码非 utf-8 | `set PYTHONIOENCODING=utf-8` |
| pytest 段错误（macOS） | sklearn 先于 torch 导入触发 libomp 重复加载 | `tests/conftest.py` 已在收集前预导入 torch；单独跑脚本时先 `import torch` |
| 报告出现 `MISS: torch 不可用` | 未装 torch，工单主路径无法实跑 | 装 `torch==2.14.0`；不装则改交实测最优 sklearn 模型，C 档"说明 LSTM 增益"如实判缺 |
| 报告出现"预测曲线未真实落盘" | 未装 matplotlib（Agg 后端） | 装 `matplotlib==3.11.0`；缺它 D 档"完成预测与可视化"判缺——环境也是选型维度 |
| 档位与上次不同 | 改了 `config/rules.yaml` 的 `tiers.*` 或 `windows` | `git diff` 看配置；工单数字（0.15/0.12/0.10）不得改动，改动即造假的判据 |
| 想验证"档位是算出来的" | — | `python run.py --set mse_b=0.0001` → 同一实测 MSE 立刻不达 B（证明数字真的生效） |

# 02 架构说明（TOGAF 四域视角）

> 项目：轴承剩余寿命预测

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 预测性维护排程：把'坏了再修'变成'提前一个周期换件' |
| 数据架构 | 轴承退化轨迹（循环数→RMS健康指标）→ 剩余寿命标签；回归输出连续值 |
| 应用架构 | core 造轨迹/训练回归/业务解读；pipeline 输出预测 vs 真值对比 |
| 技术架构 | Python 3.12 + conda ai01；numpy/sklearn；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 退化轨迹/回归/业务解读 | `make_traj()/fit()/business_note()` |
| `pipeline.py` | 训练→评估→解读 | `run(cfg, out_dir)` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置

# 01 需求规格说明（GB/T 9385《计算机软件需求规格说明规范》）

> 项目：轴承剩余寿命预测（01-AI应用基础 · W07 第4次课）
> 文档版本：v1.0　编制日期：2026-10-14　密级：教学内部

## 1. 范围
用课程真实轴承数据（`01-AI应用基础/data/bearing_rul.npz`，30 台设备 × 每台 180 窗 × 20 列
窗口特征；不在盘时由 `core.synth_devices` 同口径合成兜底并在报告标注来源），按设备级留出
切分训练回归模型（工单指定主路径为 1 层 LSTM，hidden=32 + 全连接）预测归一化剩余寿命，
把 RMSE 翻译成业务语言（'预测误差 X% 退化区间 = 可提前 N 个维护周期介入'），并按工单
《四、验收标准》的四档**实测**判定输出可复核的达成档位。

## 3. 用户故事与验收标准
| 编号 | 用户故事 | 验收标准 |
|---|---|---|
| US-01 | 作为工程师，我希望看到预测误差而非只看分数 | 留出设备 RMSE/MAE/R²/MSE 实测 |
| US-02 | 作为班组长，我希望误差能翻译成维护决策 | 误差≈10%退化区间 |
| US-03 | 作为讲师，我希望退化曲线可视化 | `output/prediction_curve.png` 真落盘（字节从磁盘读回） |
| US-04 | 作为教师，我希望档位是算出来的而非学生自称 | `tiers.py` 按同次运行实测值判四档，测不到即判缺 + 印 MISS |

## 4. 功能需求
| 编号 | 功能点 | 说明 |
|---|---|---|
| F-01 | 数据与切分 | 真实 npz 优先、缺失同口径兜底；设备级留出防泄漏 |
| F-02 | 回归建模 | LSTM（工单指定）+ Ridge/随机森林同切分对照，逐模型留出指标 |
| F-03 | 业务解读 | RMSE→维护周期 |
| F-04 | 拐点分析 | 平滑序列实测检出拐点循环号，与机群中位参照比较，竖线画进曲线图 |
| F-05 | 窗口敏感性 | 逐窗口长度真重训真测 MSE，输出表 + 图 + CSV |
| F-06 | 四档验收判定 | D/C/B/A 机检 + 人工答辩项清单（`--tier` 打印） |

## 5. 非功能需求
| ID | 类别 | 要求 | 验证方式 |
|---|---|---|---|
| NF-1 | 可复现 | 固定随机种子，重复运行结果一致 | 二次运行 diff（实测逐项一致） |
| NF-2 | 可移植 | 必需 numpy/scikit-learn/matplotlib；torch 与 PyYAML/pycodestyle 缺失有兜底路径，但**档位口径随之变化并如实印 MISS** | `python run.py --check` + 换机运行 |
| NF-3 | 可配置 | 全部阈值/清单在 config/rules.yaml（工单数字与兜底口径分节标注） | 改配置不改代码（`--set` 或改 YAML） |
| NF-4 | 可测试 | pytest 用例 ≥ 6，覆盖正常/边界/异常 + 反向降档证明 | `pytest -q`（现 28 用例全绿） |

## 6. 接口约束
- CLI：`python run.py [--config CONFIG] [--outdir DIR] [--quiet] [--tier] [--style-only] [--check] [--set K=V]`
- 配置：`config/rules.yaml`（格式见 docs/05）
- 输出：`output/report.txt`、`output/result.json`、`output/prediction_curve.png`、
  `output/window_sensitivity.png/.csv`

# 02 架构说明（TOGAF 四域视角）

> 项目：泵类设备故障诊断分类

| TOGAF 域 | 本项目答案 |
|---|---|
| 业务架构 | 零代码体验→轻量模型，让学员第一次拿到'可运行的 AI 作品' |
| 数据架构 | 合成泵站四维特征 + 三态标签；train/test 分层划分；输出混淆矩阵与指标 JSON |
| 应用架构 | core 造数据+训练双模型+手写混淆矩阵；pipeline 编排并落盘 |
| 技术架构 | Python 3.12 + conda ai01；numpy/sklearn；pytest |

## 分层与模块职责
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 造数据/训练/混淆矩阵 | `make_data()/evaluate()/confusion()` |
| `pipeline.py` | 双模型对比流水线 | `run(cfg, out_dir)` |

## 依赖方向
```
run.py  →  pipeline  →  core（纯函数，零依赖）
               ↓           ↑
            io_utils ←── report
               ↑
            config（YAML 驱动）
```
**规则**：下层不得反向依赖上层；`core` 不 import `io_utils`（保持可单测）。

## 关键质量属性
- **可测试性**：core 为纯函数 → 单测无需 mock 文件系统
- **可配置性**：阈值全部外置 YAML
- **可复现性**：种子固定于配置

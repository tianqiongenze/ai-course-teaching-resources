# 05 运行手册

## 1. 环境准备
```bash
conda create -n ai01 python=3.12 -y
conda activate ai01
pip install -r requirements.txt      # 或 requirements.lock
```

## 2. 运行
```bash
python run.py                     # 默认配置
python run.py --config config/rules.yaml
python run.py --outdir output/
```

## 3. 配置说明（config/rules.yaml）
| 键 | 含义 | 默认 |
|---|---|---|
| data_file | 课程数据文件名（经 `io_utils.course_data()` 定位） | pump_fault.csv |
| test_size | 测试集比例（工单要求 0.25 分层） | 0.25 |
| seed | 随机种子（划分与模型共用，可复现） | 7 |
| lr_max_iter / dt_max_depth / rf_n_estimators / rf_min_samples_leaf | 三分类器参数 | 2000 / 6 / 300 / 2 |
| w_acc / w_speed / w_interp | 决策矩阵权重 | 3.0 / 1.0 / 2.0 |
| interp_lr / interp_dt / interp_rf | 可解释性登记档位（0-5） | 5 / 4 / 2 |
| acc_d / acc_c / acc_b / acc_a | 工单四档准确率门槛 | 0.75 / 0.80 / 0.85 / 0.85 |
| topk | 检索/排序取前 k | 3 |

数据目录可用环境变量覆盖：`AI_COURSE_DATA=/path/to/01-AI应用基础/data python run.py`

## 4. 输出物
| 文件 | 内容 |
|---|---|
| output/report.txt | 完整过程报告（过程性证据） |
| output/result.json | 结构化结果（供下游/答辩取数） |

## 5. 常见问题
| 现象 | 原因 | 处置 |
|---|---|---|
| `ModuleNotFoundError` | 未安装依赖 | `pip install -r requirements.txt` |
| 配置不生效 | 未传 --config | 使用默认 `config/rules.yaml` |
| 中文乱码 | 控制台编码非 utf-8 | `set PYTHONIOENCODING=utf-8` |

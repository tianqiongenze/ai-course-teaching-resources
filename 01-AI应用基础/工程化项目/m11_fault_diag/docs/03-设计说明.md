# 03 设计说明

> 项目：泵类设备故障诊断分类

## 1. 模块清单与接口
| 模块 | 职责 | 关键接口 |
|---|---|---|
| `core.py` | 真实数据加载 / NumPy 分层划分 / 训练评估 / 手写指标 / 决策矩阵 | `load_labeled_csv()/stratified_split()/evaluate()/metrics_from_confusion()/decision_matrix()/tier_of()` |
| `pipeline.py` | 三分类器对比流水线 | `build_models()/run(cfg, out_dir)` |
| `io_utils.py` | CSV/JSON、原子写、等宽表、课程数据定位 | `read_csv_rows()/fmt_table()/course_data()` |

## 2. 核心算法/规则
1. **加载**：`io_utils.course_data("pump_fault.csv")` 依次尝试 `AI_COURSE_DATA` → `../../data` → `../data` → `./data`；
   命中则读真实 450 条（列名校验、非法标签计数入 `meta.n_dropped`），未命中降级 `make_data()` 合成并在报告首行标注"不代表现场表现"。
2. **划分**：纯 NumPy 分层抽样（每类 shuffle 后按 `test_size` 取整进测试集），保证小类不在测试集缺席。
3. **指标（手写）**：由混淆矩阵算 TP/FP/FN → 各类 P/R/F1 → 宏平均；`tests/test_core.py::TC-06` 与 sklearn 同题互验（±5e-4）。
4. **决策矩阵**：精度分=实测准确率档位、速度分=实测 `fit` 秒数档位、可解释性=登记档位（LR5/DT4/RF2，答辩口述理由）；
   综合分=加权求和，权重写在 `config/rules.yaml`；首行标"交付"。
5. **档位**：`tier_of(acc, gates)`，门槛 D0.75/C0.80/B0.85/A0.85 全部取自配置。

## 3. 异常处理策略
| 异常 | 触发场景 | 处理 | 对应测试 |
|---|---|---|---|
| FileNotFoundError | 配置文件缺失 | `config.load_config()` 抛出并带上路径 | test_config.py::test_missing_config_raises |
| FileNotFoundError | 课程数据 `pump_fault.csv` 未找到 | 不报错而是**降级合成兜底**，报告首行与 `result.json.source` 标注"不代表现场表现" | test_pipeline.py::test_uses_real_dataset（缺数据时 skip） |
| ValueError | 数据文件缺少 rpm/…/label 列 | 启动即拒绝并列出实际列名 | test_core.py::test_load_missing_column_raises |
| ValueError / 解析异常 | 数据文件 0 条记录 | 抛出"数据文件为空（0 条记录）"，不让空数组流进训练 | test_core.py::test_load_empty_file_raises |
| 非法标签 | label 不在 0/1/2 | 逐行计入 `meta.n_dropped` 并跳过（不静默丢样本，报告给账） | test_core.py::test_load_real_csv_if_present |

## 4. 命名与代码规范
- PEP 8；`snake_case`（函数/变量）、`PascalCase`（类）、`UPPER_CASE`（常量）
- docstring 三件套：做什么 / 参数 / 返回
- 单元函数 ≤40 行，超过则拆分

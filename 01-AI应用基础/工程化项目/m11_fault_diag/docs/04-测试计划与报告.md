# 04 测试计划与报告（GB/T 15532《计算机软件测试规范》）

> 项目：泵类设备故障诊断分类（工单 M1.1）

## 1. 测试策略
| 层级 | 方法 | 目标 |
|---|---|---|
| 单元测试 | pytest，core 纯函数 | 覆盖正常/边界/异常三档 |
| 集成测试 | pipeline 端到端（临时目录） | 输入→输出链路正确、口径与工单一致 |
| 档位回归 | 断言工单 D/C/B 准确率门槛 | 交付模型不因改动跌破工单线 |
| 口径互验 | 手写指标 ↔ sklearn.metrics 同题比对 | ADR-001 的"先手写再与库比对" |
| 回归 | `pytest -q` 全量 | 任一改动不破坏既有行为 |

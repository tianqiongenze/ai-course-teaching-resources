# 01 需求规格说明（GB/T 9385《计算机软件需求规格说明规范》）

> 项目：泵类设备故障诊断分类（01-AI应用基础 · W04 第1次课）
> 文档版本：v1.0　编制日期：2026-10-14　密级：教学内部

## 1. 范围
读取课程真实数据集 `data/pump_fault.csv`（450 条×5 维），用带标签历史数据训练三态分类器（正常/轴承磨损/叶轮堵塞），输出准确率/精确率/召回率/F1（宏平均）与混淆矩阵，并把漏报（故障判为正常）单独统计——漏报是产线最贵的错误；最终以决策矩阵选定交付模型。

## 3. 用户故事与验收标准
| 编号 | 用户故事 | 验收标准（工单 M1.1 第四节） |
|---|---|---|
| US-01 | 作为学员，我希望跑通第一个AI作品 | 及格(D) 准确率≥0.75 |
| US-04 | 作为学员，我希望指标达标良好档 | 良好(C) 准确率≥0.80 且指标解读准确 |

| US-03 | 作为讲师，我希望结果可复现 | random_state 固定、二次运行 diff 为空 |

## 4. 功能需求
| 编号 | 功能点 | 说明 |
|---|---|---|
| F-01 | 真实数据加载 | `io_utils.read_csv_rows` → `core.load_labeled_csv`，缺数据才降级合成 |
| F-02 | NumPy 分层划分 | 纯 NumPy 实现 test_size=0.25 分层抽样（工单第①条） |
| F-03 | 三分类器 | LR / DT / RF 同台（工单第②条） |
| F-04 | 四项指标 | acc / 精确率 / 召回率 / F1（宏平均），手写并可库比对（第③条） |
| F-05 | 决策矩阵 | 精度取实测准确率、速度取实测训练耗时、可解释性取登记档位（第④条） |

## 5. 非功能需求
| ID | 类别 | 要求 | 验证方式 |
|---|---|---|---|
| NF-1 | 可复现 | 固定随机种子，重复运行结果一致 | 二次运行 diff |
| NF-2 | 可移植 | 仅标准库 + numpy、scikit-learn；任意 conda 环境可跑 | 换机运行 |
| NF-3 | 可配置 | 全部阈值/清单在 config/rules.yaml | 改配置不改代码 |
| NF-4 | 可测试 | pytest 用例 ≥ 6，覆盖正常/边界/异常 | `pytest -q` |

## 6. 接口约束
- CLI：`python run.py [--config CONFIG] [--outdir DIR] [--quiet]`
- 配置：`config/rules.yaml`（格式见 docs/05）
- 输出：`output/report.txt`、`output/*.json`

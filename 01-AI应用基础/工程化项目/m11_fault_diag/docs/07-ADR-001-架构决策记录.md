# 架构决策记录 ADR-002：数据源取真实 CSV，合成数据仅作降级兜底

- 状态：已接受
- 日期：2026-10-28
- 决策者：项目组

## 背景
初版 `core.make_data()` 造合成高斯数据，`io_utils.read_csv_rows()` 写了却没被调用；
工单 M1.1 第一节明确"数据：`data/pump_fault.csv`（450 条，含少量噪声样本）"，
且旧版报告准确率 0.707 跌破工单 D 档 0.75。

## 备选方案
A 只用合成数据（可跑，但指标与工单数据集无关）｜
B 只用真实 CSV（贴合工单，但换机房缺文件就崩）｜
C 真实 CSV 优先 + 缺文件降级合成并在报告首行标注（推荐）

## 决策
**采用：C。`io_utils.course_data()` 依次尝试 `AI_COURSE_DATA` → `../../data` → `../data` → `./data`；
命中即用真实数据；未命中才用 `make_data()`，报告与 `result.json` 的 `source` 字段必须写明"合成兜底……不代表现场表现"。**

## 理由
真实数据是工单验收口径；同时保留"环境/数据也是选型维度"的课堂降级能力，且降级不造假——
报告文本自带口径标注，教师与学生都能一眼分辨。

## 后果
- 实测：450 条、5 维、三类各 150；NumPy 分层划分 336/114；LR 0.9825、DT 0.9825、RF 0.9912（macro-F1 0.9826/0.9826/0.9912）。
- 交付模型由决策矩阵选出的 LR（可解释性优先）准确率 0.9825 ≥ B 档 0.85。
- 代价：新增路径解析与列校验代码；缺数据时指标不可用于档位判定（`test_pipeline.py` 用 skip 明示）。
